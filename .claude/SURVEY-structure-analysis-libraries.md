# 調査メモ: 単語のつながりから文章の構造・論理を解析するライブラリ

- 調査日: 2026-08-08
- 目的: 文章内の単語のつながりをもとに，文章の構造や論理を解析する Python / R のライブラリを整理する．
- 位置づけ: moranajp の後段(形態素解析の結果を受けて構造を取り出す層)の候補調べ．
  実装の予定を決めたものではない．

## 全体像

「単語のつながり」は粒度で3層に分かれ，層ごとに使う道具が違う．

| 層 | 見るもの | 日本語での第一候補 |
| ---- | ---- | ---- |
| 1. 文内 | 係り受け(構文木) | GiNZA (Python) / udpipe (R) |
| 2. 文間・文章全体 | 談話関係・修辞構造 | KWJA (Python) |
| 3. 統計的な共起 | 語の共起ネットワーク | quanteda + ggraph (R) |

## 1. 文内のつながり(係り受け・構文解析)

いちばん実用的で，日本語でも道具がそろっている層．

### Python

- **GiNZA** (spaCy 上の日本語モデル `ja_ginza`)．
  UD (Universal Dependencies) 準拠の係り受けを返す．
  `token.head`, `token.dep_` で主語・目的語・修飾関係をたどれる．
  日本語ならまずこれ．
- **Stanza** (Stanford NLP)．多言語 UD．日本語モデルあり．
- **KWJA** (京大)．形態素・係り受けに加えて，述語項構造・照応・談話関係まで
  一気に出す統合解析器．「論理」まで踏み込むならこれが最有力．
- **pyknp** (KNP)．格解析(誰が・何を・どうした)に強い古参．

### R

- **udpipe**．R 単体で完結する UD 係り受け解析器(日本語モデルあり)．
  Python への依存が無いのが利点．
- **spacyr**．reticulate 経由で spaCy / GiNZA を呼ぶ．
- **rsyntax**．udpipe / spacyr の解析結果に対して木のパターンを問い合わせ，
  「誰が何をした」「何が何を引き起こす」といった構造を抽出する．
  構文木から意味の型を取り出したいときに効く．

### moranajp との関係

- moranajp には `add_depend_ginza()` があるので，GiNZA を使う経路はすでにある．
- R 側で完結させたい場合の代替は **udpipe + rsyntax**．

## 2. 文間・文章全体のつながり(談話構造・修辞構造)

「論理の流れ」を明示的に解析したいならこの層．
研究段階の道具が多く，R にはほぼ無い．

- **KWJA**．日本語の談話関係(原因・理由・条件・対比など)をラベル付けする．
  日本語では事実上の第一候補．
- **isanlp_rst** / **DPLP** / **NeuralRST**．
  RST (修辞構造理論) パーサ．文章を「核-衛星」の木にする．主に英語．
- **discopy**．PDTB 形式の浅い談話解析(英語)．

## 3. 語の共起ネットワーク(統計的なつながり)

構文ではなく「どの語とどの語が一緒に出るか」をグラフにする方向．
探索的な分析や，テキストマイニングの図に向く．

- **R**: quanteda の `fcm()` → igraph / tidygraph / ggraph で描画．
  **textnets** も同じ系統．
  moranajp で分かち書きした結果をそのまま流せる．
- **Python**: networkx + gensim / scikit-learn．

## 選び方のまとめ

- 日本語で「文の構造 + 論理関係」を一気に取りたい → **KWJA** (Python)
- 日本語で係り受けを安定して取り，後段を自分で書く
  → **GiNZA** (Python) / **udpipe + rsyntax** (R)
- R で完結させたい → **udpipe + rsyntax**，可視化は ggraph
- 図として「語のつながり」を見せたい → moranajp + quanteda + ggraph

## 注意点

- RST や議論構造 (argument mining) のように「論理そのもの」を扱う層は，
  既製ライブラリの精度が日本語ではまだ低い．
  実務では「係り受け + ルール」か，LLM に構造化出力させる方が当たりが良いことが多い．
- この調査はモデル内の知識にもとづくもので，各ライブラリの最新の対応状況
  (日本語モデルの有無・メンテ状況)は未検証．
  採用を決める前に各リポジトリを確認すること．
